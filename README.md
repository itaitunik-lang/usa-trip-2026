# Yosemite ו‑Grand Circle — אתר הטיול

אתר חי לטיול 5–15 באוגוסט 2026.
**https://itaitunik-lang.github.io/usa-trip-2026/**

---

## מה יש באתר

תפריט נפתח מהלוגו בפינה השמאלית העליונה, עם ארבעה מסכים:

| מסך | מה יש בו |
|---|---|
| 🗺️ **המסלול** | יום‑יום עם תחנות, רקע לכל מקום, מפה מוטמעת ותחזית מזג אוויר בצלזיוס |
| 📝 **משימות פתוחות** | מה עוד לא נסגר, לפי דחיפות. הסימון נשמר בדפדפן |
| 🎒 **מה ללבוש** | המלצות לכל יום, נגזרות מאופי היום ומהתחזית בפועל |
| 💳 **הוצאות** | סיכום מהקבלות בתווית `USA TRIP` ב‑Gmail |

התחזית מגיעה מ‑[Open‑Meteo](https://open-meteo.com) (בלי מפתח API), עד 15 יום קדימה.
לימים רחוקים יותר מוצג ממוצע רב‑שנתי לאוגוסט, מסומן בקו מקווקו.

## מבנה הקבצים

```
index.html            כל העיצוב והלוגיקה
data/days.json        המסלול — ימים, תחנות, קואורדינטות, אופי היום
data/tasks.json       משימות פתוחות וסגורות
data/expenses.json    הוצאות מהקבלות
tools/sync.sh         commit + push לאתר החי
tools/extract_receipts.py   מחלץ סכומים ממיילים של קבלות
```

**כדי לשנות תוכן — עורכים את קבצי ה‑JSON, לא את `index.html`.**

## איך זה מתעדכן

הכול נמצא בתיקייה הזו, שהיא גם מאגר git. כל commit ל‑`main` מתפרסם אוטומטית ב‑GitHub Pages תוך כדקה.

```bash
./tools/sync.sh
```

בנוסף רצה משימה מתוזמנת שלוש פעמים ביום (08:00, 14:00, 20:00) שסורקת את תווית `USA TRIP` ב‑Gmail, מעדכנת את `data/expenses.json` ו‑`data/tasks.json` אם נכנסה קבלה או הזמנה חדשה, ודוחפת גם שינויים שנעשו כאן בתיקייה.

### תצוגה מקומית

הדפים טוענים JSON ב‑`fetch`, אז פתיחה ישירה של הקובץ ב‑`file://` לא תעבוד. צריך שרת קטן:

```bash
python3 -m http.server 8899
```
