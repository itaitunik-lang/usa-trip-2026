# מסלול Yosemite ו‑Grand Circle — אתר טיול

אתר סטטי (עמוד יחיד) עם כל תכנית הטיול: ניווט בין הימים, כרטיס לכל יעד עם רקע, **מפה מוטמעת לכל מקום**, ורשימת **המלצות חמות 🔥** לכל יום.

הכול נמצא בקובץ אחד: `index.html` (בלי תלות חיצונית, בלי מפתח API — המפות מוטמעות מ‑Google Maps).

---

## איך מעלים ל‑GitHub Pages (בחינם)

1. היכנסו ל‑[github.com](https://github.com) וצרו חשבון (אם אין).
2. לחצו **New repository** → תנו שם, למשל `usa-trip-2026` → **Public** → **Create**.
3. במסך הריפו לחצו **uploading an existing file** וגררו את `index.html` (ואת `README.md`). לחצו **Commit changes**.
4. **Settings** → בתפריט הצד **Pages**.
5. תחת *Build and deployment* → *Source* בחרו **Deploy from a branch**, ענף **main**, תיקייה **/(root)** → **Save**.
6. המתינו ~דקה. הכתובת תופיע למעלה בעמוד Pages, בפורמט:
   `https://<שם‑המשתמש>.github.io/usa-trip-2026/`

זהו — האתר חי וזמין מכל מכשיר. כל עדכון של `index.html` בריפו יתעדכן אוטומטית באתר.

> טיפ: אם רוצים כתובת קצרה יותר, אפשר לקרוא לריפו `<שם‑המשתמש>.github.io` והאתר יעלה ישירות בכתובת הזו.

## מה כולל האתר
- **11 ימים** (5–15 באוגוסט 2026), ניווט בלשוניות למעלה + כפתורי הקודם/הבא.
- לכל יעד: אייקון, שעה, **רקע קצר**, דגשים, **מפה מוטמעת**, וקישור לפתיחה ב‑Google Maps.
- **המלצות חמות** לכל יום.
- סימון הזמנות: ✅ מוזמן / ⚠️ עדיין להזמין.
- עברית מלאה (RTL), נגיש למקלדת ולנייד.
