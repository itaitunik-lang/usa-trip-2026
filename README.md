## עובד בלי אינטרנט

בזיון, ברייס, אנטלופ ומוניומנט ואלי אין קליטה. `sw.js` שומר במכשיר את כל הדפים, הנתונים והאיורים בביקור הראשון, והאתר נפתח במלואו גם בלי רשת.

- **הקבצים הקבועים** נטענים מהמטמון קודם — פתיחה מיידית.
- **`data/*.json`** נטענים מהרשת קודם ונופלים למטמון — כדי שהסנכרון האוטומטי לא ייתקע על נתונים ישנים.
- **התחזית האחרונה נשמרת** ומוצגת כשאין רשת, במקום ליפול לממוצע הרב‑שנתי.

- **`index.html` עצמו נטען מהרשת קודם** ונופל למטמון רק כשאין חיבור. זה מה שמבטיח שדיפלוי נכנס לתוקף ברענון אחד, ולא נתקעים על עיצוב ישן.

בגלל שה‑HTML הוא network-first, **אין חובה** להעלות את `CACHE` בכל שינוי ב‑`index.html` — הוא ייתפס לבד. כן כדאי להעלות אותו כשמוסיפים או משנים **נכסים קבועים** (תמונות, אייקונים, קבצים חדשים ב‑`SHELL`), כדי לוודא שהמטמון הישן נמחק.

> אזהרה מהניסיון: עד גרסה v3 ה‑HTML היה cache‑first, וזה גרם לכך שתיקון עיצובי שכבר היה חי בשרת פשוט לא הופיע בדפדפן. אם נתקלים במשהו שנראה "לא התעדכן" — לבדוק ב‑DevTools → Application → Service Workers לפני שמחפשים באג ב‑CSS.

## מבנה הקבצים

```
index.html            כל העיצוב והלוגיקה
sw.js                 service worker — תמיכה באופליין
manifest.webmanifest  הגדרות התקנה כאפליקציה
data/days.json        המסלול — ימים, תחנות, קואורדינטות, אופי היום
data/tasks.json       משימות פתוחות וסגורות
data/flights.json     קטעי הטיסה ורשימת הבדיקות
data/emergency.json   חירום, תדלוק ואזורי זמן
data/places.json      רקע על כל אתר — משויך ליום דרך שדה iso
data/packing.json     רשימת הציוד — סעיפים, כמויות ומה לא להביא
data/expenses.json    הוצאות מהקבלות
images/               איור נוף לכל יום
icons/                אייקונים למסך הבית ולדוק
tools/sync.sh              commit + push לאתר החי
tools/extract_receipts.py  מחלץ סכומים ממיילים של קבלות
tools/make-icons.sh        מרנדר מחדש את האייקונים מהלוגו
tools/make_day_art.py      מייצר מחדש את איורי ה‑SVG (fallback)
tools/fetch_day_photos.py  מוריד את תמונות הימים מ‑Commons + כותב CREDITS.md
images/CREDITS.md          מקור, צלם ורישיון לכל תמונה
```

**כדי לשנות תוכן — עורכים את קבצי ה‑JSON, לא את `index.html`.**

### תמונות לימים

לכל יום יש עכשיו תמונה אמיתית מהמקום, ב‑`images/day-<iso>.webp` (~130KB כל אחת, ~2MB הכול). הן הורדו מ‑Wikimedia Commons תחת רישיונות פתוחים בלבד (CC0, Public Domain, CC BY/BY‑SA) — הקרדיטים המלאים בקובץ [`images/CREDITS.md`](images/CREDITS.md). איורי ה‑SVG המקוריים (מ‑`tools/make_day_art.py`) נשארו כ‑fallback ונטענים אוטומטית אם יום כלשהו יאבד את שדה ה‑`img` שלו.

**להחליף תמונה לאחרת:**

1. עדכנו את `PHOTOS` ב‑`tools/fetch_day_photos.py` עם ה‑title המדויק מ‑Commons, או שימו קובץ משלכם ישירות ב‑`images/day-<iso>.webp`.
2. אם דרך הסקריפט: `rm images/day-<iso>.webp && python3 tools/fetch_day_photos.py` (הוא מדלג על קבצים קיימים, אז תמיד למחוק קודם).
3. הסקריפט דוחה אוטומטית כל רישיון שאינו CC0/Public Domain/CC BY(-SA) — אין דרך "לטעות" ולהכניס תמונה עם רישיון בעייתי.
4. עדכנו את `imgAlt` לאותו יום ב‑`data/days.json`.
5. אם שיניתם שם קובץ (לא רק תוכן) — לעדכן את `DAY_NUMS`/`SHELL` ב‑`sw.js` ולהעלות את `CACHE`.

מפרט: WebP, 1600×640, עד ~148KB. גיבוי לתמונה מקורית לא נשמר בריפו — רק ה‑title ב‑`PHOTOS` מצביע חזרה למקור.

## איך זה מתעדכן

התיקייה הזו היא מאגר git, וכל commit ל‑`main` מתפרסם ב‑GitHub Pages תוך כדקה.

```bash
./tools/sync.sh
```

בנוסף רצה משימה מתוזמנת שלוש פעמים ביום (08:07, 14:07, 20:07) שסורקת את תווית `USA TRIP` ב‑Gmail, מעדכנת את `data/expenses.json` ו‑`data/tasks.json`, ודוחפת גם שינויים שנעשו כאן בתיקייה.

### תצוגה מקומית

הדפים טוענים JSON ב‑`fetch`, אז פתיחה ישירה ב‑`file://` לא תעבוד:

```bash
python3 -m http.server 8899
```
